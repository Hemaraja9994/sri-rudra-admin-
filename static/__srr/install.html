Install the admin app

Open the clinic portal from its own icon: on your computer's taskbar or Dock, or on your phone's Home Screen. Same sign-in, always up to date.

  1. Open admin.srirudraspeechandhearing.com in Google Chrome or Microsoft Edge.

  2. Click Install app under the sign-in box, or the install icon at the right end of the address bar.

  3. Click Install.Sri Rudra opens in its own window and stays in your Start menu or Dock.

Install icon not showing?
  • Chrome: open the ⋮ menu, then Cast, save and share, then Install Sri Rudra.
  • Edge: open the … menu, then Apps, then Install this site as an app.
  • Safari on a Mac: choose File, then Add to Dock.
  • Firefox can't install apps. Please use Chrome or Edge.
